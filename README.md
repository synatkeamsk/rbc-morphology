# SmearScope: Red Blood Cell Morphology Classification

A modular deep learning framework designed for automated classification of red blood cell (RBC) morphology from peripheral blood smear images.

## Project Goal
Classify erythrocyte variants (distinguishing normal red blood cells from abnormal morphological subtypes) to assist in automated screening protocols linked to underlying hematologic conditions.

## Repository Structure
- `src/`: Data preprocessing, model architectures, training loops, and inference logic.
- `notebooks/`: Google Colab exploration and model training experiments.
- `app/`: User interface and deployment scripts.
- `docs/`: Dataset notes, morphologic criteria, and validation plans.
